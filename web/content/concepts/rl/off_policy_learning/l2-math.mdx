## Formal definition

Off-policy learning allows the agent to learn a target policy $\pi$ from data generated by a different behavior policy $\pi_\beta$. The key challenge is correcting for the distribution mismatch. Importance sampling corrects expectations: $\mathbb{E}_{a \sim \pi}[f(a)] = \mathbb{E}_{a \sim \pi_\beta}\left[\frac{\pi(a|s)}{\pi_\beta(a|s)} f(a)\right]$. For full trajectory correction: $\rho_{0:T} = \prod_{t=0}^{T} \frac{\pi(a_t|s_t)}{\pi_\beta(a_t|s_t)}$, which has exponential variance in $T$. Q-learning is inherently off-policy because the Bellman optimality backup $Q(s,a) \leftarrow r + \gamma \max_{a'} Q(s',a')$ does not depend on the data-generating policy. On-policy methods (PPO, TRPO, A2C) require fresh data from the current policy $\pi_\theta$ for each update.
