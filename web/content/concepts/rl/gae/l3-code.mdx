## The 15 lines every PPO implementation shares

<CodeWalk title="GAE-Lambda over a rollout buffer">

```python title="gae.py"
import torch

@torch.no_grad()
def compute_gae(rewards, values, dones, last_value, gamma=0.99, lam=0.95):
    """rewards, values, dones: tensors of shape (T,) from one rollout.
    last_value: V(s_T) for bootstrapping the final partial episode.
    Returns (advantages, returns), both (T,)."""
    T = rewards.shape[0]
    adv = torch.zeros(T)
    next_adv, next_value = 0.0, last_value

    for t in reversed(range(T)):
        not_done = 1.0 - dones[t]                       # 0 at true terminals
        delta = rewards[t] + gamma * next_value * not_done - values[t]
        adv[t] = delta + gamma * lam * not_done * next_adv
        next_adv, next_value = adv[t], values[t]

    returns = adv + values                              # critic targets
    return adv, returns
```

Two outputs, two jobs: `adv` weights the policy gradient (after per-batch
normalization), `returns = adv + values` is the regression target for the
critic — algebraically the λ-return, for free.

</CodeWalk>

## Reading the dial

```python
lam = 0.0   # A_t = delta_t           -> pure TD: low variance, biased by V errors
lam = 0.95  # the default that works almost everywhere
lam = 1.0   # A_t = G_t - V(s_t)      -> pure Monte Carlo: unbiased, high variance
```

With a freshly initialized (useless) critic, λ near 1 keeps learning alive
because Monte Carlo returns don't depend on V being right. As the critic
improves, the bias term shrinks and the variance reduction dominates — which
is why 0.95 wins in practice without annealing.

<KeyIdea>

GAE is exponential smoothing over n-step advantage estimators:
$\hat{A}^{GAE} = \sum_l (\gamma\lambda)^l \delta_{t+l}$. One reversed loop, one
hyperparameter, and it subsumes "n-step returns" as special cases. If you
can write this loop on a whiteboard with both `done` zeroings in the right
place, you understand on-policy credit assignment.

</KeyIdea>

<Warning>

Compute GAE with the values that *collected* the data (`no_grad`, before the
epoch loop) — recomputing advantages inside PPO epochs with the updating
critic is a subtle nonstationarity bug. And normalize `adv`, never
`returns`: the critic needs targets in the true return scale.

</Warning>
