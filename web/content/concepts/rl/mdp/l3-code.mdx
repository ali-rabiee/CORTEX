## An MDP is just arrays

Strip away the formalism and an MDP is five Python objects. Making them
concrete once — by solving a toy problem *exactly* — permanently demystifies
what every deep RL algorithm is approximating.

<CodeWalk title="A 4×4 gridworld MDP, solved exactly with value iteration">

```python title="gridworld_vi.py"
import numpy as np

N = 4                       # 4x4 grid -> S = 16 states
S, A = N * N, 4             # actions: up, right, down, left
GOAL, PIT = 15, 5
MOVES = [(-1, 0), (0, 1), (1, 0), (0, -1)]

# --- The model: P (S, A, S') and R (S, A) ----------------------------
P = np.zeros((S, A, S))
R = np.full((S, A), -0.04)            # small step cost
for s in range(S):
    if s in (GOAL, PIT):
        P[s, :, s] = 1.0              # absorbing
        continue
    r, c = divmod(s, N)
    for a, (dr, dc) in enumerate(MOVES):
        nr, nc = r + dr, c + dc
        s2 = s if not (0 <= nr < N and 0 <= nc < N) else nr * N + nc
        P[s, a, s2] += 0.8            # intended move
        for slip in ((a - 1) % 4, (a + 1) % 4):   # 10% slip each side
            dr2, dc2 = MOVES[slip]
            nr2, nc2 = r + dr2, c + dc2
            s3 = s if not (0 <= nr2 < N and 0 <= nc2 < N) else nr2 * N + nc2
            P[s, a, s3] += 0.1
R[:, :] += 0.0
R[[GOAL, PIT], :] = 0.0               # absorbing states pay nothing
# reaching them pays via the transition INTO them:
for s in range(S):
    for a in range(A):
        R[s, a] += P[s, a, GOAL] * 1.0 + P[s, a, PIT] * -1.0

assert np.allclose(P.sum(-1), 1.0)    # every (s,a) row is a distribution

# --- Value iteration --------------------------------------------------
gamma, V = 0.99, np.zeros(S)
for it in range(1000):
    Q = R + gamma * P @ V             # (S, A): the Bellman lookahead
    V_new = Q.max(axis=1)
    if np.abs(V_new - V).max() < 1e-8:
        break
    V = V_new

policy = Q.argmax(axis=1)             # greedy policy, exact optimum
print(f"converged in {it} iterations")
print(V.reshape(N, N).round(2))
```

Forty lines, no learning, no neural networks — and it finds the provably
optimal policy. Every quantity deep RL estimates with samples (`Q`, `V`, the
greedy policy) is computed here exactly because we *have* `P` and `R`.

</CodeWalk>

<KeyIdea>

RL in one sentence: **the same `Q = R + γ P V` backup, when `P` and `R` are
unknown and you only get samples from them.** Q-learning replaces the
expectation `P @ V` with a sampled `r + γ max Q(s', ·)`; policy gradients
bypass `Q.argmax` with a differentiable policy. The gridworld is the ground
truth those approximations chase.

</KeyIdea>

<Warning>

The robotics gap: real state spaces are continuous, so `P` is a density you
can't tabulate, and the Markov property fails the moment you feed raw camera
frames (partial observability). When something breaks downstream, return to
this level and ask: *what would the tabular version of my problem look like,
and which assumption did I just violate — Markov state, known model, or
discrete enumerability?*

</Warning>
