## One algorithm, three eras

**Consolidation (2013–2018).** Six independent fixes to DQN's biases and
variance merged into Rainbow; its ablation table is still the cheat-sheet
for which value-learning tricks matter.

**Robot scale (2018–2023).** QT-Opt swapped the argmax for CEM and bought
grasping from half a million real attempts; Q-Transformer tokenized actions
so offline Q-learning could ride transformers and mixed-quality datasets.
The through-line: value learning's superpower is *reusing any data*.

**Efficiency frontier (2023–).** BBF showed value-based agents can be both
sample-efficient and strong with scaled networks + reset schedules —
keeping model-free value learning competitive with world models on small
budgets.
