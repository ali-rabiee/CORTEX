## The three losses, exactly as implemented

<CodeWalk title="SAC update step (twin critics, tanh-Gaussian actor, auto-α)">

```python title="sac_update.py"
import torch
import torch.nn.functional as F

def sac_update(batch, actor, q1, q2, q1_targ, q2_targ,
               log_alpha, opts, gamma=0.99, tau=0.005, target_entropy=None):
    obs, act, rew, obs2, done = batch
    alpha = log_alpha.exp().detach()

    # ---- Critic update --------------------------------------------------
    with torch.no_grad():
        dist2 = actor(obs2)
        act2 = dist2.rsample()                      # fresh action from CURRENT policy
        logp2 = dist2.log_prob(act2).sum(-1, keepdim=True)
        q_targ = torch.min(q1_targ(obs2, act2), q2_targ(obs2, act2))
        y = rew + gamma * (1 - done) * (q_targ - alpha * logp2)   # soft target

    q_loss = F.mse_loss(q1(obs, act), y) + F.mse_loss(q2(obs, act), y)
    opts.q.zero_grad(); q_loss.backward(); opts.q.step()

    # ---- Actor update (gradients flow THROUGH the action) ---------------
    dist = actor(obs)
    a = dist.rsample()                              # tanh(mu + sigma*eps)
    logp = dist.log_prob(a).sum(-1, keepdim=True)
    q_min = torch.min(q1(obs, a), q2(obs, a))
    actor_loss = (alpha * logp - q_min).mean()
    opts.actor.zero_grad(); actor_loss.backward(); opts.actor.step()

    # ---- Temperature update: hold entropy near target -------------------
    target_entropy = target_entropy or -act.shape[-1]    # -dim(A)
    alpha_loss = -(log_alpha * (logp + target_entropy).detach()).mean()
    opts.alpha.zero_grad(); alpha_loss.backward(); opts.alpha.step()

    # ---- Polyak-average target critics ----------------------------------
    with torch.no_grad():
        for p, pt in zip(list(q1.parameters()) + list(q2.parameters()),
                         list(q1_targ.parameters()) + list(q2_targ.parameters())):
            pt.mul_(1 - tau).add_(tau * p)
```

Note what is *not* here: no target actor (the current policy supplies a'),
no exploration noise schedule (entropy is the exploration), and replay-buffer
actions `act` appear only in the critic loss — the actor always re-samples.

</CodeWalk>

## The tanh squash, done right

```python title="tanh_gaussian.py"
class TanhGaussian(torch.nn.Module):
    def forward(self, obs):
        mu, log_std = self.net(obs).chunk(2, -1)
        log_std = log_std.clamp(-5, 2)              # numerical guardrail
        base = torch.distributions.Normal(mu, log_std.exp())
        return torch.distributions.TransformedDistribution(
            base, [torch.distributions.transforms.TanhTransform(cache_size=1)]
        )
```

The `TanhTransform` applies the change-of-variables correction
$\log p(a) = \log p(u) - \sum_i \log(1 - \tanh^2(u_i))$ for you — hand-rolling
that correction with the wrong sign is the classic source of "SAC entropy
goes to −∞" bugs.

<KeyIdea>

SAC's robustness comes from three interlocking choices: **twin critics**
kill overestimation, **entropy in both losses** keeps exploration coherent
with valuation, and **auto-α** turns the exploration-exploitation dial into
a constraint (target entropy) you almost never retune. Default
hyperparameters work across most of MuJoCo/ManiSkill — which is exactly why
SAC is the off-policy baseline for real-robot learning.

</KeyIdea>
