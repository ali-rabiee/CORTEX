## Formal definition

The complete workflow from data collection through deployment: (1) collect demonstrations/sim data, (2) preprocess and curate dataset, (3) train policy with experiment tracking, (4) evaluate in simulation, (5) sim2real validation, (6) deploy with monitoring. Each stage has specific tooling: DVC for data versioning, W&B for training, Docker for reproducibility, CI/CD for automated testing. The pipeline must be reproducible: any deployed model can be traced back to its exact dataset, code version, and hyperparameters.
