## Formal definition

Robot Operating System (ROS/ROS2) is the standard middleware for robot software, providing inter-process communication (topics, services, actions), hardware abstraction (URDF, drivers), and a rich ecosystem of packages (MoveIt, Nav2, perception pipelines). ROS2 uses DDS (Data Distribution Service) for real-time communication with QoS (Quality of Service) policies. Key concepts: nodes, topics (pub/sub), services (request/reply), actions (long-running tasks with feedback), tf2 (transform tree), and launch files.
