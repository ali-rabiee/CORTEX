## Formal definition

Pixel-level identification of object instances in a scene. Instance segmentation assigns each pixel a label $y_i \in \{0, 1, \ldots, K\}$ where $K$ is the number of instances. Semantic segmentation labels each pixel by class. Panoptic segmentation combines both. For robotics: SAM (Segment Anything Model) provides zero-shot segmentation from prompts (points, boxes, or text).
