## Formal definition

Batch normalization normalizes activations across the mini-batch dimension for each feature independently, then applies a learnable affine transform: $$\hat{x}_i = \frac{x_i - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}, \quad y_i = \gamma \hat{x}_i + \beta$$ where $\mu_B = \frac{1}{m} \sum_{i=1}^{m} x_i$ and $\sigma_B^2 = \frac{1}{m} \sum_{i=1}^{m} (x_i - \mu_B)^2$ are batch statistics. During inference, running averages $\mu_{\text{run}}$ and $\sigma^2_{\text{run}}$ (computed via exponential moving average during training) replace batch statistics.
