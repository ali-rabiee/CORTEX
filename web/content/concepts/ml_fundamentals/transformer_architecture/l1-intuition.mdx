## Read it as a stream, not a stack

The standard diagram encourages you to see a transformer as a pile of blocks,
each transforming its predecessor's output. The more useful reading — and the one
that matches how these models behave — is a **residual stream**: a vector per
position that runs unobstructed from input to output, which each block *reads
from* and *writes back to*.

<Figure src="/figures/transformer-residual-stream.svg"
        alt="Left: a pre-norm block, with the residual stream running straight down and normalisation inside each of the attention and feed-forward branches. Right: a post-norm block, with the normalisation sitting on the stream after each addition."
        caption="The residual path is an identity. In pre-norm it stays that way, so the gradient reaches every layer directly; in post-norm every layer's gradient passes through L normalisations, which is why the original formulation needed a warmup." />

<Intuition>
A shared notebook passed down a line of specialists. Each one reads what is
relevant, thinks, and writes an addition — nobody rewrites the page. So something
written on page one is still legible at the end, and a specialist halfway down can
respond to it directly.

Replace that with each person rewriting the page in their own words, and by the
tenth the original is gone.
</Intuition>

<KeyIdea>
Depth is trainable because the residual path is an *identity*. The gradient
reaches layer 1 without passing through anything that could shrink it, however
many layers there are. That single structural fact is what separates a trainable
100-layer network from an untrainable one, and it predates transformers.
</KeyIdea>

## Where the norm goes, and why it matters

<Steps>
<Step title="Pre-norm — normalise inside the branch">
$x \leftarrow x + \text{Attn}(\text{norm}(x))$. The stream itself is never
normalised, so the identity path is preserved exactly. Trains at depth from step
one with no warmup, and is what essentially every model since 2020 uses.
</Step>

<Step title="Post-norm — normalise the stream">
$x \leftarrow \text{norm}(x + \text{Attn}(x))$. The original formulation. Every
layer's gradient now passes through $L$ normalisations on its way back, and the
scale of that gradient depends on depth — which is why it needs a learning-rate
warmup and diverges without one.
</Step>
</Steps>

<Warning>
This is the single most common inherited bug when someone adapts an older
implementation. It does not error; the model simply refuses to train at depth,
and the response is usually to add a warmup schedule and spend a day tuning it —
solving a problem that `norm_first=True` removes.

Pre-norm has its own cost, worth knowing: because the stream is never normalised,
its variance grows with depth, so a final normalisation before the output head is
required rather than optional.
</Warning>

## Where the parameters actually are

Per layer, with the standard $4\times$ feed-forward expansion:

$$
\underbrace{4d^2}_{\text{attention: } W_Q, W_K, W_V, W_O}
\;+\;
\underbrace{8d^2}_{\text{FFN: } d\to4d\to d}
\;=\; 12d^2
$$

<KeyIdea>
Two thirds of the parameters are in the feed-forward blocks — and since the FFN
also dominates the arithmetic at ordinary sequence lengths, most of the compute
too. The architecture is named after its minority component. If you are deciding
where to spend an optimisation effort, that is worth noticing.
</KeyIdea>

Two pieces of arithmetic worth carrying:

$$
N \;\approx\; 12\,L\,d^2 \quad\text{(non-embedding parameters)}
\qquad\qquad
C \;\approx\; 6\,N\,D \quad\text{(training FLOPs for } D \text{ tokens)}
$$

At $L = 32$, $d = 4096$: about 6.4 billion parameters, plus roughly 0.13 billion
per embedding matrix at a 32k vocabulary — which is what a model described as
"7B" typically is.

## The parts, and what each is for

<Steps>
<Step title="Attention — moving information between positions">
The only operation that mixes across the sequence. Everything else acts
positionwise.
</Step>

<Step title="The feed-forward block — computing at a position">
Two matrices with a nonlinearity between them, applied identically at every
position. Most of the parameters, most of the FLOPs, and — on the interpretability
evidence — plausibly where factual associations are stored.
</Step>

<Step title="Normalisation — keeping activations in scale">
LayerNorm or RMSNorm, per position across the feature dimension. Not a
regulariser; a conditioning device that keeps the inputs to each branch in a
range the initialisation assumed.
</Step>

<Step title="Positional information — because attention has none">
Attention over a set is permutation-equivariant: shuffle the inputs and the
outputs shuffle with them. Position has to be injected, and how you inject it
determines whether the model extrapolates beyond its training length.
</Step>
</Steps>

<Warning>
That last point is easy to underrate. Attention genuinely has no notion of order —
without positional information a transformer cannot distinguish "dog bites man"
from "man bites dog". Absolute learned embeddings work and stop at the trained
length; rotary and bias-based schemes encode *relative* position and extrapolate
much better, which is why they replaced learned embeddings almost universally.
</Warning>
